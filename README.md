# Banking Management System

A beginner-friendly Python-based Banking Management System that simulates basic banking operations through a command-line interface.

## Features

- Create a new bank account
- PIN-based login
- Deposit money
- Withdraw money
- Check account balance
- Transfer money between accounts
- View transaction history
- Multiple account support
- JSON-based permanent data storage
- Basic input validation

## Technologies Used

- Python
- JSON
- File Handling
- Functions
- Dictionary
- Loops
- Conditional Statements
- Exception Handling
